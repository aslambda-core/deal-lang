# DEAL — Часть 6: РИСКИ И ДОРОГА (реестр, плюсы по болям дня, ступени, целесообразность)

Мастер: [DEAL.md](DEAL.md).

ПРИНЦИП ЯЗЫКА (слово владельца 14.11): DEAL — универсальный язык для CPU И GPU. Как это устроено: программа DEAL говорит «что», примитивник (замороженный, подменяемый) говорит «где» — CPU-питон, CPU-натив, GPU-ядра; сделки — чистые функции, потому GPU-батчи и горизонтальный масштаб ложатся без переписывания (§3.5 призрачные ступени). Части: [2](DEAL_YAZYK.md) · [3](DEAL_KOMPILYATOR.md) ·
[4](DEAL_ROY_I_MODELI.md) · [5](DEAL_AGI_OBUCHENIE.md).

## §2. Плюсы — каждый привязан к живой боли одного дня (13.11)

| # | Плюс | Боль дня, от которой он |
|---|---|---|
| 1 | Отказ словами на первом касании — петля чинения умирает | NameError `import time` в recepty — погоня через exec живого исходника |
| 2 | Один канон ввозов и написания — «два судьи одного правила» невозможны | панельная видимость в tablitsa ОТДЕЛЬНО от RECIPES; «неизвестная служба» на первом подъёме |
| 3 | Одна кодировка и одно написание enforced | cp1251 у heredoc; edinoobrazno (111 из 240 команд за форму) |
| 4 | Мини-файлы не размножаются: правка адресуется договором, не «где это живёт» | вырезка по маркерам съела RECIPES целиком; 1877 файлов <100 строк |
| 5 | Декомпиляция = печать: источники не теряются никогда | борьба с index.lock чужих снимков; обнулённые файлы (NTFS) |
| 6 | Верификация вместо веры: правдоподобное не проходит | фон-кладка с «Убедиться…» при команде — шов дня |
| 7 | Замки-гонки уходят: летопись CAS + O_EXCL канонизированы языком | два index.lock за вечер; гонка .chast аренды |
| 8 | Токены: чтение нужного договора вместо файла целиком | чтение 600 строк ради точки правки (~8к токенов) |
| 9 | Рой готов принять .deal сегодня | прецедент fon_razlozhit_sluzhba: карта файлов ломтика уже отработана |
| 10 | Дом канонизирует своё: DEAL вырастает из мерил/оракулов/летописи, не из головы | разведка дома: 15 пунктов «дом уже формализует» (часть 1 §1) |

## §3. Дорога — пять ступеней со стоп-условиями

| Ступень | Что строится | Срок (ПРОЕКТ-МЕРКА) | Выход-рубильник | СТОП-условие (идём обратно) |
|---|---|---|---|---|
| 0 | Корпус договоров: мерки/оракулы/шапки дома → спецификация языка; список примитивников заморожен | ~1 неделя | корпус одним списком полезен сам — даже при отказе от DEAL | — (ступень 0 безобидна) |
| 1 | Питон-ВМ + компилятор (8 стадий); 3 пилотных компонента (оракул, счётчик полки, поиск TF-IDF) | 2–4 недели | 3 компонента зелёные; слайс ≤3к токенов; отказы понятны ≥90% | множитель токенов >5 устойчиво |
| 2 | Самокомпиляция DEAL→DEAL | 4–8 недель | байт-в-байт совпадение с питон-версией по золотому корпусу | расхождения не сходятся за 2 итерации |
| 3 | Миграция конвейера: кладки DEAL на малых руках, оракулы DEAL, ломтики служб | месяцы | ≥60% карточек DEAL закрыты без человека | кладки DEAL хуже питон-кладок по доле закрытий |
| 4 | Натив: свой байткод → машинный код горячего подмножества | месяцы | судьи/оракулы в нативе быстрее питона ×N; хеш-сверка работает | натив не даёт выигрыша |

**Статус песка 19.11** (E:\DEAL_PILOT, вне дома; REPORT.md — полная летопись):
ступени 1–3 ЗАКРЫТЫ (S1 25/25 байт-в-байт, C-семя 55/55, самкомпиляция
27/27), ступень 4 живёт: эмиссор x86-64 НА DEAL, суд-самоприменимость
8 стадий True, S4b слот-прямо (накопление ×0.83 БЫСТРЕЕ раста), S5
двуязычие rus/eng 10/10×2, S4c-шаг-1 списки в нативе (массив int64 в
данных, элемент/длина, вложенные циклы), S4c-шаги 2–3 SSE2-редукция:
примитивник сумма(м) излучается нативом inline-рутиной (179 байт: 4×paddq,
16 элементов/итерацию, адрес-прогрессия, хвост movq в лейн) — ред_чист
81.92M элементов: DEAL и раст сопоставимы (×0.8–1.6 по окнам, обе стороны
векторные), против питона ×1350+; пробник 24/24, лестница зелёная (суд
9/9, S1 25/25, S3 27/27, S5). Чистый ×2 от раста на векторной задаче
упирается в SSE2-порты этой машины (нет AVX2) — форма рутин масштабируется
в ymm без изменения языка, ×2 исполняется на AVX2-железе.
Слово владельца 15.11 «DEAL целиком самостоятельный ЯП» исполняется.

После каждой ступени — слово владельца. Ступень 0 запускается отдельно и независимо
(полезна сама: дом впервые увидит свои договоры одним списком).

## §3.5. ПРИЗРАЧНЫЕ СТУПЕНИ (зафиксированы словом владельца 14.11:
«делаем универсальный и для CPU И для GPU ЯЗЫК» — принцип универсальности
бэкендов; каждая призрачная ступень стартует по слову владельца, тяжелея
самого языка не меняет):

| Призрак | Что это | Почему честно отложено |
|---|---|---|
| **GPU-бэкенд примитивника** | примитивник получает GPU-ядра: сортировка/сумма/максимум (редукции), хеш-батч, поэлементная математика; компилятор детектит батч-зовы (одинаковый зов в цикле с независимыми данными) и маршрутизирует на GPU | программа DEAL целиком на GPU ляжет плохо: последовательность+ветвления+файлы = анти-профиль GPU; зато свидетели батчем (10000 независимых кейсов одной сделки) и редукции примитивника — идеальны (×10–100 на больших N) |
| **Масштаб** | полка → БД за тем же договором; DEAL-службы → stateless-рой за балансировщиком; кластеры | файлы-полка служат десяткам потоков, не миллионам пользователей; сделки — чистые функции, масштабируются горизонтально бесплатно — но инфраструктура отдельная большая дорога |

Меры в пользу GPU уже в языке: сделки — чистые функции (вход→выход, состояние
только на полке), примитивник заморожен (ядра подменяемы без правки программ),
батчи независимы по конструкции (свидетели не делят состояние). При миллионах
пользователей или тяжёлых батчах — слово владельца поднимает призрака.

## §4. Три сценария целесообразности — цена и результат

| Сценарий | Цена | Результат через год | Когда выбирать |
|---|---|---|---|
| А. Весь дом на DEAL (решение владельца как цель) | большая: годы моста, компилятор, миграция, LoRA | дом на языке, где галлюцинация структурно невозможна; канон против всех хворь дня; натив где горячо | вера в путь «код только за AGI» до конца |
| Б. Только горячие места (судьи, оракулы, поиск — 5–10%) | средняя: ступени 0–2 + пилот | быстрый верифицируемый слой судов; питон-дом живёт как был; мост мал | осторожная проверка гипотезы с рубильниками |
| В. Отказ от DEAL | малая: только ступень 0 | корпус договоров дома одним списком (навык и прибор) — ценен и без языка; вопрос закрыт словом | если пилот провалит рубильники |

Рекомендуемая дорога внутри любого сценария: **ступень 0 → пилот ступени 1 → замер
рубильников → слово владельца**. Целесообразность — не вопрос веры: критерии в мастере §7
считаются домом автоматически.

## §5. Если DEAL не выживет — что остаётся

1. **Корпус договоров дома** одним списком — впервые: мерки, оракулы, шапки, границы.
   Основа для любых будущих форм (Rust-переписывание тоже начнётся с него).
2. **Приборы**: слайс-дверь, суд свидетельств (края/скрытые/подгонки), рубильники токенов —
   полезны питон-конвейеру без всякого DEAL.
3. **Опыт миграции по компонентам за договорами** — переносится на любую целевую форму,
   включая Rust и «новый язык» в любом виде.
4. Ничего не удаляется: недошедшие ступени уходят в карантин `_to_delete/<что>_<дата>/`
   (железное правило дома).

## §6. Слова владельца, на которых стоит вся записка

- «Код точно остаётся только за AI и AGI» (14.11) — человек читает и судит, не правит.
- «прям концептуально новом с нуля сформированном ЯП… низкоуровневый или высокоуровневый
  тут решаешь ты» (14.11) — решено: два яруса одного языка (§ дороги, часть 3 §4).
- «не по таймеру — по событию» (13.11) — дорога ступенями по рубильникам-событиям,
  не по календарю: каждая ступень стартует по слову владельца при зелёных рубильниках.
- «Мы с тобой обсудим целесообразность» (14.11) — эта записка и есть предмет обсуждения;
  строительство начинается только после вердикта.
