## 1. Гипотеза одной строкой

**ИИ ненадёжен не в написании кода, а в свободном текстовом канале к нему**: галлюцинация
живёт там, где ИИ может написать «похоже на правду» и это куда-то попадёт. DEAL убирает
канал: ИИ не редактирует текст — ИИ подаёт **верифицируемые превращения** над каноничным
AST, а компилятор единственный касается кода и судит каждую сделку машинно.

Дом уже живёт так де-факто (живые пути):

| Изобретение дома | Где живёт | Что это в DEAL |
|---|---|---|
| Мерило «сейчас → цель» + исполнимая проверка | `lib/rd_pretenzii.py` (pretenzii_k_merilu) | постусловие сделки |
| Оракул, «истинен без проекта» | `RnD/oraculy/` (395 файлов), `RnD/oraculy/ORAKUL.py` | свидетель-исполнение |
| Шапка-контракт (ЗАЧЕМ/ГРАНИЦА/ОТКУДА КОД) | `lib/cpr_ispolnit.py`, `lib/postanovka.py` | договор |
| Шаг с проверкой, статусы зелёный/красный | `lib/rd_zadachi.privesti_shagi` | превращение и его суд |
| Летопись + замок отката | `lib/rd_zadachi._zapis_letopisi`, `lib/detect_rollback` | журнал превращений (историю нельзя укорачивать) |
| Заданник пар (показанные ведут, скрытые судят, края обязательны) | `tools/zadachi.py`, `data/zadachi/prinyatye.json` | алгоритм судьи свидетельств |
| DSL-синтез формул (копейки, проценты, списки) | `lib/sintez_dsl.py` | предок канона операций и отказов (ERROR_INVALID_INPUT) |
| Кладка {spec, tests, meta}, суд hoden | `mcp_qwen_coder/most_nasos.py` | кладка DEAL |

DEAL не изобретает — **канонизирует** то, что дом уже сделал и проверил боем.

## 2. Конвейер одной картинкой

```
 ИИ (голова/руки/LFM/облако)
      │  подаёт ПРЕВРАЩЕНИЕ (атомарная операция над AST: ввести-сделку, заменить-тело…)
      ▼
 КОМПИЛЯТОР DEAL (8 стадий)
      │  суд полноты → суд выполнимости → исполнение свидетелей
      │  → серийный хеш → летопись → реестр
      │  ОТКАЗ — всегда словами (виновник+причина+что править), канон Otkaz дома
      ▼
 .deal-КОМПОНЕНТ = канон-AST (единственный источник)
      │                     └──▶ ПРОЕКЦИЯ (читаемый вид, печатается из AST всегда)
      ▼
 РОЙ: служба дома (рецепт+таблица+пульс) · кладка между узлами (полка, sha256)
      · судьи (d1, оракулы) · песочница для карантинного яруса
```

## 3. Пример за 60 секунд

Задача из реального синтеза дома (Б5, «цена за единицу»).

**(а) Человек читает проекцию** (печатается компилятором из AST, вид один для всех):

```
договор деление(а: число, б: число) -> число
  требует  б != 0
  даёт     округлено(а / б, 2)
  отказ    деление_на_ноль

сделка цена_за_единицу(месячный: число, человек: число) -> число
  тело:
    цена  = деление(месячный, человек)
    верни цена
  свидетель:
    месячный=100000, человек=4 -> 25000.00
    месячный=100000, человек=0 -> отказ деление_на_ноль
```

**(б) Хранится канон-AST** (единственный источник; фрагмент, см. часть 2 §4 полностью):

```json
{"сделка": "цена_за_единицу",
 "входы": [{"имя": "месячный", "тип": "число"}, {"имя": "человек", "тип": "число"}],
 "выход": "число",
 "тело": [{"оп": "присваивание", "имя": "цена",
           "что": {"оп": "зов", "договор": "деление",
                   "аргументы": [{"оп": "поле", "имя": "месячный"},
                                 {"оп": "поле", "имя": "человек"}]}},
          {"оп": "верни", "что": {"оп": "поле", "имя": "цена"}}],
 "свидетель": [{"вход": {"месячный": 100000, "человек": 4}, "выход": 25000.00},
               {"вход": {"месячный": 100000, "человек": 0}, "отказ": "деление_на_ноль"}]}
```

**(в) ИИ работает превращениями, не текстом** (лог одной кладки):

```
1. ввести-сделку  цена_за_единицу (договор + 1 свидетель-кейс)      → принята
2. добавить-кейс   месячный=100000, человек=0 -> отказ деление_на_ноль → принята (край)
3. заменить-тело   (цена = деление(...); верни цена)                → принята
   компилятор: исполнил 2 кейса в песочнице — оба сошлись, хеш записан, летопись растёт
```

Текст «похоже на правду» в этой цепочке **некуда вписать**: каждый шаг либо судится
машиной, либо отвергнут словами.

## 5. Свойства-обещания (каждое с механизмом)

1. **Декомпиляция всегда и без потерь** — исходник DEAL это AST; проекция = детерминированная
   печать AST (part 2 §3). Потерял проекцию — напечатается заново; потерял AST — летопись+полка
   восстанавливают (превращения обратимы, прецедент замка отката `lib/detect_rollback`).
2. **Канон**: одно написание, одна кодировка utf-8, один вид каждой конструкции —
   класс хворь «python3/py/-X utf8, два судьи, cp1251» исчезает (уроки `lib/postanovka.edinoobrazno`,
   `lib/pechat_utf8.py`).
3. **Адрес = хеш договора** — компоненты узнают друг друга по содержанию, не по путям;
   вольные зависимости невозможны.
4. **Летопись вшита в рантайм** — каждое превращение записано было→стало, историю нельзя
   укорачивать (прецедент `lib/rd_zadachi._zapis_letopisi`).
5. **Свидетельства машинны** — вердикт всегда считан (исполнение кейсов), не прочитан.
6. **Отказ всегда словами** — компилятор отвечает в каноне Otkaz дома: виновник, причина,
   что править (урок железного правила «отказ не бывает молчаливым»).
7. **Режимы экспорта** — компонент отдаётся наружу прозрачным .deal или нативом без AST;
   AST всегда остаётся в полке дома (part 2 §3.5).

## 6. Плюсы и минусы — свод

**+** Убирает петлю чинения (главный жегатель токенов), канон против четырёх хворей дня,
декомпиляция как печать, свидетельства вместо веры, рой готов принять (прецедент
`pulse/fon_razlozhit_sluzhba.py`), масштаб переносится по компонентам.

**−** Дорогой старт (×2–5 токенов на компонент в первые недели), мост двуязычья на годы,
канон-жёсткость душит «творческие» правки (нужен карантинный ярус), первый интерпретатор
пишется вслепую один раз, двойное хранение (AST+проекция), любой получивший .deal понимает
всё мгновенно (защита — доступ к полке + натив-экспорт, не формат).

Полный реестр с вероятностями и смягчениями — часть 6.

## 8. Дорога — пять ступеней (подробно в части 6)

0. **Корпус договоров** — извлечь мерки/оракулы/шапки дома в спецификацию (полезна и без DEAL).
1. **Питон-ВМ** — интерпретатор AST + 8 стадий, части ≤600 строк; 3 пилотных компонента.
2. **Сам себя** — компилятор переписан на DEAL, байт-в-байт совпадает с питон-версией по золотому корпусу.
3. **Миграция конвейера** — кладки DEAL на малых руках, оракулы DEAL.
4. **Натив** — свой байткод → кодогенерация в машинный код; храповик 600 умирает с питоном.
