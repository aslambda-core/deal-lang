Мастер: [DEAL.md](DEAL.md). Всё ниже — ПРОЕКТ на живой машине обучения дома.

## §1. Вход в язык — двери, не весами (сначала)

Дом уже умеет вводить AGI в любую область тремя дверями — DEAL получает те же:

**Дверь 1 — навык-звонок** (прецедент `.agents/skills/atlas-system/SKILL.md`;
перенос навыков `lib/roy_kross_navyk.py`, дверь пути `lib/navyk_put.py`):

```markdown
---
name: deal
description: Язык DEAL (.deal) дома AI_AUTO — использовать при ЛЮБОЙ работе с
  .deal-компонентами: подача превращений, чтение проекции, суд свидетелей,
  кладки DEAL, слайс спецификации. Двери: слайс-дверь, компилятор, реестр.
---
# Skill: deal
## Шаг 1 — возьми слайс
python tools/deal.py слайс <имя-договора>   # 2–3к токенов: договор + превращения + 3 примера
## Шаг 2 — работай превращениями
подавай операции закрытого набора (часть 2 §5); компилятор судит на первом касании
## Шаг 3 — читай отказы словами
каждый отказ: {стадия, виновник, причина, что_править} — исправляй по словам
## Не делай
не редактируй AST руками; не пиши проекцию руками — она печатается компилятором
```

**Дверь 2 — атлас** (прецедент: 6485 страниц, поиск FTS5 без векторов —
`tools/atlas.py спроси`, `lib/atlas_poisk.py`): 5 страниц спецификации
(язык, превращения, компилятор, примитивник, отказы-канон) ищутся тем же поиском
по докстрингам и страницам.

**Дверь 3 — слайс-дверь** (новая, ~100 строк): `tools/deal.py слайс` печатает
**только нужный кусок** — договор цели, набор превращений, 3 примера, канон отказов.

## §2. Слайс-дверь — договор на сам язык

Правило-обещание языка самому себе (проверяется на ступени 1 как мера):

> **Полный слайс, достаточный для кладки, влезает в 2–3 тысячи токенов.**

| В слайс входит | Не входит (подгружается по запросу тем же поиском) |
|---|---|
| договор цели (+2 вспомогательных) | чужие договоры глубже двух звеньев |
| закрытый набор 16 превращений (таблица — ~800 токенов) | полный реестр компонент |
| канон отказов (список имён + 3 примера формата) | летопись чужих компонентов |
| 3 полных примера (деление, счётчик полки, кладка-лог) | примеры, не относящиеся к цели |
| суд краёв (5 правил заданника) | история языка |

Если слайс не влезает — это претензия К ЯЗЫКУ, не к модели: язык обязан резаться
(правило «сделка = атом»; разбор части 2 §5, превращение 11).

## §3. LoRA-корпус — веса после вердиктированных следов

Контур уже живёт: `tools/trener_lora.py` (первый контур опыт→веса, RD-S03-20261022164853329-3),
корпус 1250 примеров `data/korpus/korpus_20261022.jsonl`, лосс 3.4→1.88–2.1, адаптер→GGUF
(`tools/konverter_lora_gguf.py`) → боевой слот. Ключевое правило тренера сохраняется:
**в SFT только следы с внешним вердиктом**; отрицательные — отдельно (DPO/ORPO).

Внешний вердикт DEAL-следа — **сам компилятор**: кладка дошла до 8/8 стадий = след зелёный;
отвергнутая серия превращений = отрицательный след для DPO. Точный формат (без изменений
тренера):

```json
{"messages": [
  {"role": "system",    "content": "<слайс: договор цели + превращения + 3 примера>"},
  {"role": "user",      "content": "закрой сделку цена_за_единицу: кейсы из карточки"},
  {"role": "assistant", "content": "[{\"превращение\": \"ввести-сделку\", ...},\n"
                                   " {\"превращение\": \"добавить-кейс\", ...},\n"
                                   " {\"превращение\": \"заменить-тело\", ...}]"}
]}
```

Оценка стартового корпуса (ПРОЕКТ-МЕРКА): один пилотный компонент ≈ 20–40 превращений;
3 пилотных компонента + миграция кладок ≈ 100–300 следов — первый LoRA v1 реален в первый
месяц боя (прецедент: v1 127 реплик → v2 147 реплик, −10,3% лосса).

## §4. «Выучила ли модель язык?» — гейт «немерено не процент»

Живой урок дома: перенос навыков замерен честно — **0,49%** (`lib/roy_kross_navyk.py`,
кросс-прогон 108×36, 4 исхода). Заявление «малая выучила DEAL» проверяется тем же способом:

| Гейт | Мера | Прецедент |
|---|---|---|
| Кросс-прогон DEAL-задач | чужая задача × модель: доля «решил» до заявления | `lib/roy_kross_navyk.py` (порог ставит владелец) |
| Отказы компилятора исправлены без человека | ≥90% кладок | журнал компилятора (часть 3 §2) |
| Ось «Цена усвоения» продолжают мерить | навык «куплен», если потребовал ≤1 показа внешней модели; замер дома 25.10 — 76,39% | `state/profil_osi/um.py`, `tools/merilo_osi.py` |
| Обратная сверка | разбор(печать(AST)) == AST на корпусе — язык не расползается | часть 2 §2 биективность |

## §5. Таблица обучения малых LFM — недели и вердикты

| Фаза | Кто учился чем | Вердикт-критерий |
|---|---|---|
| Неделя 0 | сессии + голова: слайс-дверь, 3 пилотных компонента руками | корпус следов ≥100; отказы понятны без человека ≥90% |
| Неделя 1–2 | малые LFM 8B/24B: кладки по слайсу, промпт-only | ≥60% кладок закрыты ИИ; множитель токенов ≤2 |
| Неделя 3–4 | LoRA v1 на корпусе следов (тренер `tools/trener_lora.py`, режим обучения — модели спят) | лосс ниже v0 на корпусе; кросс-прогон ≥ порога владельца |
| Месяц 2+ | LoRA v2 (как у тренера: v1 127 → v2 147 реплик, −10,3%) | доля карточек DEAL, закрытых без человека, растёт |
| Рубильник | если множитель >2 устойчиво — язык пересматривается | слово владельца |

## §6. Как AGI (большой) учится языку глубже — не промптом одним

| Механизм дома | Что даёт для DEAL |
|---|---|
| Семблок + TF-IDF по меткам владельца (`lib/semant_retr.py`) | метки владельца на проекциях → спецификация поднимается наверх поиска |
| Банк знаний + связи (`knowledge.db`, 35 938 рёбер) | «договор X противоречит договору Y» — связи между компонентами |
| Пересмотр правил (`lib/pereSmotr_pravil.py`, банк 45 правил) | правила языка (запреты §6 части 2) пополняются по случаям, устаревшие снимаются |
| Атлас-слова («что не видно из докстринга / чем куплено / чего не умеет») | каждое решение языка получает слово — AGI входит через смысл, не через синтаксис |
| Дневники (`data/pamyat/dnevnik.jsonl`, `chronicle.jsonl` 3335 записей) | следы всех кладок DEAL — сырьё корпуса и оси |

## §7. Честные границы обучения

1. Миллиардов строк .deal не будет никогда — опора в спецификации и компиляторе, не в
   памяти весов: это не беда, это дизайн (урок атласа: FTS5, не вектора — «зависимость
   от службы эмбеддингов сделала бы поиск недоступным»).
2. Синтаксис питона будет протекать в .deal на старте (известная хворь чужих языков) —
   компилятор отсеивает на стадии 1 словами; протечки в корпус не попадают (не вердиктированы).
3. LoRA учит МОДЕЛЬ, а не дом: реестр, летопись и полка остаются источником истины —
   модель, забывшая язык, войдёт через слайс за 2–3к токенов.
